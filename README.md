# Spain Collection — Clone

A responsive clone of the Spain Collection website built using modern web technologies like React.js, React Router DOM, Framer Motion, Tailwind CSS, and Lenis for smooth scrolling. This project aims to replicate the original website's functionality and design while showcasing seamless animations, efficient routing, and modern styling practices.
