# Spain Collection — Frontend Rebuild Study

A frontend rebuild of the Awwwards-featured Spain Collection site, built to study how its scroll timing works. React, React Router DOM, Framer Motion, Tailwind CSS, Lenis and Swiper, on Vite.

This is a rebuild study, not a product. The art direction belongs to the original; the implementation is mine. It covers one of four layers on purpose — the frontend choreography. No backend, no data layer and no persistence: the catalogue is static.
